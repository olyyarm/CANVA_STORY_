# Изменения

## Исходные проблемы

- основной сценарий падал без Mistral API и не имел тестового режима;
- канва не масштабировалась, а pan/drag использовали рассинхронизированные координаты;
- ноды накладывались, не выбирались, не меняли размер и не удалялись безопасно;
- длинный текст был слишком мелким, overflow и кнопки работали непоследовательно;
- отсутствовали localStorage, новый проект, полный сброс, экспорт и импорт;
- GitHub Pages получал секрет в публичную клиентскую сборку;
- исходный lint содержал 8 ошибок и 1 предупреждение;
- документация не соответствовала фактическому коду.

## Что исправлено

- добавлен полностью локальный тестовый режим и аккуратный API-клиент с отменой;
- основной путь создаёт визуальный сценарий и сценовые ноды за одно действие;
- повторная генерация обновляет связанные ноды и сохраняет ручные координаты;
- детали сценария создаются в предсказуемой раскладке без наложения;
- master prompt можно создать даже при частично заполненных деталях;
- добавлены понятные loading, success, error, disabled и cancel состояния;
- pan, zoom вокруг курсора, fit, center, drag и resize работают в общей системе координат;
- добавлены selection, каскадное удаление, клавиши `Delete` и `Esc`;
- интерфейс собран в единой нейтральной тёмно-серой системе;
- добавлены автосохранение, восстановление viewport, новый проект и полный сброс;
- добавлены JSON export/import, схема документа v1 и проверка входных данных;
- тяжёлые изображения и временные URL исключены из localStorage и JSON;
- добавлен Error Boundary;
- публичный GitHub Pages workflow переведён на тестовый режим без API-ключа;
- обновлены README, title страницы и метаданные.

## Следующий рекомендуемый этап

Добавить безопасный backend proxy и поверх существующей схемы v1 реализовать библиотеку постоянных персонажей и локаций. Сценовые ноды должны ссылаться на сущности через `entityRef`, а изображения храниться в IndexedDB или объектном хранилище. Только после этого имеет смысл добавлять эпизоды, производственные статусы и motion-промпты для режима видеоманхвы.
