# CANVA STORY

CANVA STORY — локальная визуальная мастерская для разработки сценария. Пользователь вводит исходный текст, задаёт количество сцен и получает связанный граф: визуальный сценарий, сцены, описания героев, локаций и настроения, а затем text-to-image промпты.

Приложение сохраняет проект в браузере и работает без внешнего API на встроенных тестовых данных. Это стабильная основа существующего проекта, а не отдельный прототип конвейера видеоманхвы.

## Что умеет приложение

- превращать исходный текст в заданное количество сцен;
- создавать и обновлять карточки героев, локаций и настроения;
- собирать англоязычный визуальный промпт для отдельной сцены;
- строить ассоциативные ветки для слова или образа;
- перемещать и изменять размер нод;
- панорамировать канву и масштабировать её вокруг курсора;
- центрировать граф и показывать весь проект;
- выделять и каскадно удалять ноды с подтверждением;
- автоматически сохранять проект в `localStorage`;
- экспортировать и импортировать версионированный JSON;
- создавать тестовый кадр без внешнего API.

## Быстрый запуск

Требуется Node.js 20 или новее.

```bash
git clone https://github.com/olyyarm/CANVA_STORY_.git
cd CANVA_STORY_
npm ci
npm run dev
```

Откройте адрес, который покажет Vite, обычно `http://localhost:5173/CANVA_STORY_/`.

На Windows после установки зависимостей можно также запустить `start.bat`.

## Работа без API

Никакая настройка не нужна. Если `VITE_MISTRAL_API_KEY` отсутствует, приложение автоматически включает тестовый режим. Он проходит весь основной путь и создаёт предсказуемые локальные данные без сетевых или платных генераций.

Для явного включения режима скопируйте `.env.example` в `.env`:

```env
VITE_MOCK_MODE=true
VITE_MISTRAL_API_KEY=
```

## Локальное подключение Mistral

В локальном `.env`:

```env
VITE_MOCK_MODE=false
VITE_MISTRAL_API_KEY=your_local_key
```

Поддерживаются проверенные псевдонимы `mistral-small-latest` и `mistral-large-latest`.

Важно: Vite встраивает все переменные `VITE_*` в клиентский JavaScript. Такой ключ виден пользователю сборки и не является секретом. Не добавляйте реальный ключ в публичный GitHub Pages deploy. Для безопасного production-подключения нужен серверный proxy — это отдельный следующий этап.

## Локальное подключение LM Studio

В верхней панели приложения есть переключатель режима генерации: «Тест», «Mistral API» и «LM Studio». При выборе LM Studio появляются поля endpoint и model.

По умолчанию используется:

```text
http://localhost:1234/v1/chat/completions
```

Если LM Studio запущен на другом домашнем компьютере, укажите адрес этой машины в локальной сети, например:

```text
http://192.168.1.10:1234
```

Приложение само добавит `/v1/chat/completions`, если указан только базовый адрес. В поле model впишите имя модели, загруженной в LM Studio. Настройки сохраняются в браузере локально.

Если приложение открыто с GitHub Pages по HTTPS, браузер может заблокировать обычный `http://192.168...` адрес домашней сети. Для такого режима надёжнее запускать приложение локально через `npm run dev` или поставить перед LM Studio HTTPS/proxy.

## OpenAI GPT-5.6 Luna через прямой API

В текстовых режимах доступен `OpenAI · Luna Direct API`, а в рендере ассетов — `OpenAI Direct · GPT Image 2 Low`. Оба режима обращаются прямо к официальному OpenAI API и не используют ComfyUI Partner-ноды или Comfy Credits. Секретный ключ остаётся в локальном Node-сервисе CANVA STORY и никогда не попадает в браузер, JSON проекта или переносимый ZIP.

Создайте игнорируемый локальный конфиг, если его ещё нет:

```bat
copy start_canva_story_local_config.example.bat start_canva_story_local_config.bat
```

Добавьте в него собственный ключ:

```bat
set "OPENAI_API_KEY=ваш_секретный_ключ"
```

Затем полностью закройте старые окна CANVA STORY и запустите `start_canva_story_full_stack.bat`. В строках конфигурации должно появиться `OPENAI_API_KEY=configured`. В интерфейсе выберите `OpenAI · Luna Direct API`; стартовая глубина рассуждения `MEDIUM` подходит для обычной работы. Увеличение до `HIGH`, `XHIGH` или `MAX` может замедлить ответ и повысить расход выходных токенов.

API-биллинг OpenAI отделён от подписки ChatGPT. Согласно [официальной карточке GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna), модель стоит `$0.20` за 1 млн входных и `$1.20` за 1 млн выходных токенов; бесплатный API-tier модель не поддерживает. CANVA STORY не отправляет платный тест автоматически: расход начинается только после вашей команды генерации текста.

Не используйте имя `VITE_OPENAI_API_KEY`: все `VITE_*` переменные встраиваются в клиентскую сборку и перестают быть секретными. Для Luna и GPT Image 2 допустимо только серверное имя `OPENAI_API_KEY`.

## Профили стоимости Gemini

При выборе `Gemini · ComfyUI` рядом появляется профиль стоимости текста:

- `Экономный` — все текстовые операции выполняет `Gemini 3.1 Flash-Lite` с `LOW` thinking;
- `Сбалансированный` — сценарий, сюжетные дополнения, Scene Writer, диалоги и закадр используют выбранную Gemini-модель, а извлечение героев и локаций, память, резюме, TTS-очистка и image prompts автоматически переходят на `Gemini 3.1 Flash-Lite` с `LOW` thinking;
- `Максимум` — сохраняет ручной выбор модели, thinking и максимального ответа для каждой операции.

Для старых локальных настроек автоматически включается `Сбалансированный`. Профиль влияет только на будущие текстовые запросы и не запускает перегенерацию готовых материалов. Поле максимального ответа остаётся общим верхним пределом; экономный маршрутизатор дополнительно ставит безопасный предел по типу операции, чтобы случайный слишком длинный ответ не расходовал лишние токены.

## Генерация кадров

### Живое фэнтези и магическая экономика

Новый проект получает обновлённую «Библию фэнтези-стиля»: painterly high-fantasy manhwa, самоцветная холодная палитра, цветной магический свет и функциональная магическая инфраструктура вместо постоянной жёлто-коричневой суровости. Для старого проекта стандартная неизменённая библия обновляется при следующей загрузке автоматически; вручную отредактированная версия сохраняется как пользовательская.

Рядом с базами создаётся редактируемая нода «Системное правило · магическая экономика». Для брокера, трейдера, риск-менеджера и аудитора она переводит финансовые понятия в физические законы мира: ликвидность становится доступным запасом маны, активы — правами на потоки или заряженными носителями, залог — источником, кристаллом, контуром или клятвой, маржинальное требование — обязательным пополнением заряда, дефолт — разрывом печати и отключением магической функции. Правило подключено к зерну истории, плану глав, базе, материалу, сценам и памяти, поэтому установленные ресурсы, единицы и ограничения должны сохраняться между главами.

Готовый текст и изображения не перегенерируются автоматически. Чтобы преобразовать уже написанную главу, повторно соберите её материал и сценарий; чтобы перестроить весь сезон, сначала обновите зерно и планировщик глав в копии проекта.

В верхней панели есть отдельный переключатель генерации изображений: `Pollinations` или `ComfyUI`.

Для ComfyUI по умолчанию используется:

```text
http://localhost:8188
```

В поле checkpoint укажите имя SDXL checkpoint из папки `ComfyUI/models/checkpoints`, например:

```text
SDXL\sd_xl_base_1.0.safetensors
```

Pipeline основного кадра выбирается один раз в поле `Compose` ноды «Таймлайн». В сценах остаётся единая команда «Объединить»: она берёт общий референс из ноды «Локации», канонические изображения персонажей из реестра и запускает выбранный Compose. После успешной генерации приложение запрашивает готовую картинку через ComfyUI `/view` и отправляет `/free` с `unload_models: true`, чтобы выгрузить модель из памяти, если включён переключатель «Выгружать».

Если браузер блокирует запросы к ComfyUI, запустите ComfyUI с CORS для локального интерфейса, например с параметром `--enable-cors-header`, и для адресов домашней сети учитывайте те же HTTPS-ограничения, что и для LM Studio.

## Облачный рендер ассетов

В нодах «Герои», «Локации» и «Системные вставки» есть собственное поле «Рендер». У каждой ноды выбор сохраняется внутри проекта, поэтому одновременно можно назначить героям и локациям GPT Image 2 Low, а системным вставкам — Nano Banana. Основные сценовые кадры собираются выбранным в таймлайне Compose.

В ноде «Таймлайн» поле «Ассеты» по умолчанию использует `OpenAI Direct · GPT Image 2 Low`; локальный Z-Image, SDXL или ERNIE и прежний путь через Comfy API включаются только явным выбором. Если в таймлайне ещё нет сцен, кнопка называется «Подготовить главу»: она проверяет разбивку на главы, создаёт материал выбранной главы и запускает её автосборку. После появления сцен та же кнопка называется «Добрать недостающее». Порядок фиксирован: сначала реестр отбирает только новых персонажей, затем общие изображения создаются в ноде «Локации», после чего сцены получают основной кадр, дополнительные планы и озвучку. Системные вставки и финальный Compose сохраняют собственные настройки.

«Собрать ролик» возобновляет прерванную FFmpeg-очередь: готовые актуальные клипы сцен сохраняются в локальном AssetStore и пропускаются при повторном запуске. Если, например, ошибка произошла на клипе 13, повторный запуск продолжится с него. Клип пересобирается только после изменения его кадра, дополнительных планов, системной вставки, озвучки, фона главы или версии видеомакета.

Доступные облачные варианты:

- `OpenAI Direct · GPT Image 2 Low` — новый режим по умолчанию для героев, локаций, системных вставок и фона главы. Он использует тот же локальный `OPENAI_API_KEY`, что и Luna, но обращается к официальному Image API без ComfyUI. Для стандартного вертикального или горизонтального изображения Low официальный ориентир выходной части — около `$0.005`, дополнительно учитывается небольшой входной prompt; произвольное разрешение может немного изменить итог. Персонажи создаются в 9:16 (`1152×2048`), остальные ассеты — в 16:9 (`2048×1152`);
- `Comfy API · GPT Image 2 Low` — у героев, локаций и системных вставок; использует Partner/API-ноду `OpenAIGPTImageNodeV2`, ориентировочно `$0.0058–0.0228` за изображение; персонажи создаются в вертикальном формате 9:16 (`1152×2048`), локации и вставки — в горизонтальном 16:9 (`2048×1152`);
- `Nano Banana 2 Lite API` — дополнительный вариант только у системных вставок; использует уже подключённую Partner/API-ноду `GeminiNanoBanana2V2` в ComfyUI и Comfy.org API key, ориентировочно `$0.041` за изображение.

Платный запрос отправляется только после нажатия кнопки генерации ассетов. Прямой режим идёт через защищённый локальный шлюз на порту 4317; он не раскрывает ключ браузеру, не повторяет неопределённый платный запрос автоматически и не требует запущенного ComfyUI. Готовые изображения сохраняются обычным AssetStore проекта и при повторном «Добрать недостающее» не создаются заново. Режимы `Comfy API` и `Nano Banana` по-прежнему используют локальный ComfyUI как шлюз к Partner API.

1. Для прямого режима добавьте `OPENAI_API_KEY` в локальный конфиг и запустите полный стек.
2. В ноде или таймлайне выберите `OpenAI Direct · GPT Image 2 Low` и запускайте генерацию как обычно.
3. Если нужен старый путь, запустите ComfyUI с `OpenAIGPTImageNodeV2` и используйте Comfy.org API key из верхней панели.

Comfy.org API key хранится в localStorage конкретного браузера, а прямой OpenAI-ключ — только в локальном bat-конфиге. Старые сохранённые значения Krea, Luma и Replicate автоматически переводятся на Comfy GPT Image 2 Low при следующем запуске генерации; их не переключают на прямой платный режим без выбора пользователя.

## OmniVoice

Для локальной озвучки установите [`ComfyUI-OmniVoice-TTS`](https://github.com/Saganaki22/ComfyUI-OmniVoice-TTS) официальным `install.py`. Обычный `pip install omnivoice` без `--no-deps` использовать нельзя, поскольку он может заменить CUDA-сборку PyTorch.

Настройки раскрываются в верхней панели в секции «Озвучка»:

- `Быстрая · BF16` — модель `OmniVoice-bf16`, около 2 ГБ на диске и меньше расход видеопамяти;
- `Качественная · FP32` — полная `OmniVoice`, около 4 ГБ на диске; если модели ещё нет, официальный узел автоматически скачает её при первом запросе;
- профили качества используют 32, 48 или 64 diffusion-шагов;
- seed сохраняется в проекте: одинаковые настройки и seed дают воспроизводимый голос, а кнопка «Другой дубль» выбирает новый seed и сразу перегенерирует аудио;
- «Голос по описанию» использует `OmniVoiceVoiceDesignTTS` и только официальные теги OmniVoice; рулетка выбирает допустимый мужской пресет и новый seed, не добавляя свободный текст или тег акцента;
- `Voice Clone` использует `OmniVoiceVoiceCloneTTS`, референс чистой речи длительностью примерно 3–15 секунд и его дословную расшифровку. Заполненная расшифровка позволяет не скачивать Whisper и обычно точнее сохраняет голос.
- Скорость OmniVoice настраивается в секции «Озвучка» от `0.5` до `2.0`; значение `0.9` остаётся спокойным стартовым темпом. Изменение скорости обновляет только озвучку и зависимые клипы, не затрагивая изображения.
- «Словарь ударений и произношения» сохраняется внутри проекта и применяется перед каждым запросом TTS. Формат: одна замена `исходное = произношение` на строку. Для удобства `догов+ор` автоматически преобразуется в `догово́р`; готовый Unicode-знак ударения тоже поддерживается. После изменения словаря связанная озвучка и клипы считаются устаревшими и пересобираются без повторной генерации изображений.
- Для русского рассказчика используется стабильный режим выбора речевых токенов (`position_temperature: 0`), чтобы одинаковые слова меньше меняли произношение между сценами. Это не заменяет словарь для омографов и вымышленных имён, поскольку OmniVoice пока не гарантирует управление русским ударением.

Стартовый рассказчик — зрелый мужчина с очень низким голосом: `male, middle-aged, very low pitch`. Отдельного тега хрипотцы в OmniVoice 0.2.1 нет. Возрастной низкий пресет может дать более фактурный тембр, но для гарантированной естественной хрипотцы используйте Voice Clone.

## ElevenLabs Direct API: чистовая озвучка

В секции «Озвучка» теперь два провайдера:

- `OmniVoice Local · черновик` — бесплатная локальная речь для сборки и проверки монтажа;
- `ElevenLabs Direct API · чистовик` — финальная речь через собственную ноду `CANVA STORY ElevenLabs TTS` в локальном ComfyUI. Нода обращается прямо к `api.elevenlabs.io` и не использует Comfy Partner Credits.

Ключ ElevenLabs хранится только в игнорируемом Git локальном файле `start_canva_story_local_config.bat`:

```bat
set "ELEVENLABS_API_KEY=ваш_ключ"
```

Не добавляйте ключ в интерфейс, workflow, `project.json`, `.canva-story.zip` или отслеживаемые файлы. На домашнем и рабочем компьютере создаётся свой локальный конфиг с тем же ключом либо с разными ключами. После изменения ключа полностью перезапустите `start_canva_story_full_stack.bat`, потому что переменную окружения должна получить именно ComfyUI.

При запуске full-stack батник копирует отслеживаемую папку `comfyui_custom_nodes/CANVA_STORY_ElevenLabs_TTS` в выбранную через `COMFY_ROOT` сборку ComfyUI. Если ComfyUI уже был открыт, закройте его и запустите стек заново, чтобы новая нода зарегистрировалась.

Поддерживаются `eleven_multilingual_v2`, `eleven_v3` и `eleven_flash_v2_5`. Для Multilingual v2 локальный словарь ударений применяется к тексту до запроса. Для v3 и Flash можно дополнительно указать ElevenLabs pronunciation dictionary ID и version ID. Каждая сцена отправляется отдельно вместе с текстовым контекстом соседних сцен.

Рекомендуемый процесс:

1. Оставьте OmniVoice, нажмите «Добрать недостающее» и проверьте черновой монтаж.
2. Выберите ElevenLabs, voice ID и модель; кнопкой короткого теста проверьте голос. Полный платный тест автоматически не запускается.
3. На таймлайне нажмите «Чистовая озвучка · ElevenLabs». Перед запуском приложение покажет число символов и ориентировочную стоимость.
4. После чистовой озвучки пересоберите клипы или нажмите «Собрать ролик». Изображения не перегенерируются.

Подпись TTS учитывает очищенный текст, провайдера, голос, модель, голосовые параметры, seed, словари и контекст. Неизменённые чистовые сцены пропускаются без нового платного запроса. При обрыве очереди успешно готовые сцены сохраняются, а повторный запуск продолжает только недостающие. Автоповтор разрешён внутри собственной ComfyUI-ноды только для HTTP 429 и временных 5xx; неопределённый сетевой ответ не повторяется, чтобы не создать двойное списание.

Текст закадра создаётся как рассказ от третьего лица, понятный даже при выключенном изображении. В первой сцене и после смены места он называет локацию и участников, затем конкретное действие, сопротивление, результат и переход. Сюжетно важное видимое действие проговаривается один раз; мелкая хореография и движения камеры не перечисляются. Афоризмы ограничены двумя короткими фразами на главу и не заменяют события. Сохранённые ноды со старым промптом автоматически обновляются при следующей генерации или кнопке «Редактура закадра».

Голосовой референс хранится в локальном AssetStore и включается в переносимый `.canva-story.zip` вместе с остальными медиа. В лёгкий JSON попадает только ссылка на локальный ассет, поэтому для переноса Voice Clone между компьютерами используйте «Сохранить проект».

## Основной рабочий путь

1. В ноде нужного паспорта нажмите «Развернуть главу». Паспорт выбранной главы имеет приоритет: глобальный логлайн используется только как справка о мире, а планы соседних глав в запрос не попадают. Для главы 2 и следующих смерть, перерождение и первое пробуждение героя не повторяются, если паспорт прямо не требует флешбэк.
2. Проверьте заголовок и драматическое зерно в ноде «Материал главы», затем нажмите «Автособрать главу».
3. Откройте ноду «Герои»: фильтр покажет, сколько персонажей уже есть в реестре или предыдущих главах, повторно использует их референсы и отправит на рендер только новых.
4. Создайте общие референсы в ноде «Локации».
5. В таймлайне выберите Compose и нажмите «Добрать недостающее» для последовательной сборки медиа.
6. Для ручной работы в каждой сцене доступны только «Объединить», «Озвучить» и «Сделать клип». Дополнительные планы создаются автоматически и не требуют отдельной кнопки.

Если глава была собрана из ошибочного материала, повторно разверните именно её паспорт, проверьте новую ноду «Материал главы» и снова нажмите «Автособрать главу». При реальном изменении текста приложение сбрасывает устаревшие кадры, озвучку, клипы и итоговый ролик этой главы. Неизменённые сцены и канонические изображения персонажей сохраняются.

Новый материал главы проходит проверку причинности: в нём должно быть не меньше пяти последовательных шагов с наблюдаемым фактом, физическим действием героя, сопротивлением, непосредственным результатом и источником нового знания. Система не может сообщить герою отсутствующую улику или превратить подозрение в доказанный факт. Если первый ответ нарушает этот контракт, приложение автоматически запрашивает исправленный вариант; после второй неудачи старый материал не перезаписывается и показывается понятная ошибка.

Кнопка текущей генерации превращается в «Отменить». Готовые данные при отмене не удаляются.

## Канва

- перетаскивание фона — панорамирование;
- колесо мыши — масштаб вокруг курсора;
- перетаскивание заголовка ноды — перемещение;
- маркер в правом нижнем углу — изменение размера;
- `Delete` / `Backspace` — запрос на удаление выбранной ноды;
- `Esc` — снять выбор или закрыть подтверждение;
- «Показать всё» — вместить проект в рабочую область;
- «Центр» — центрировать проект, сохранив масштаб.

## Сохранение, экспорт и импорт

Автосохранение выполняется локально примерно через полсекунды после изменения. В верхней панели виден статус сохранения.

JSON-документ имеет `schemaVersion: 1`, стабильный `id`, метаданные проекта, ноды, viewport и секцию `extensions`. В `extensions` оставлены точки расширения для персонажей, локаций, эпизодов и ассетов.

Сгенерированные изображения, аудио и видео сохраняются в IndexedDB этого браузера. В нодах хранится стабильная ссылка на ассет, а временный `blob:` URL восстанавливается после перезагрузки. Loading-состояния и временные ошибки в проект не записываются.

Кнопка «Сохранить проект» скачивает переносимый файл `.canva-story.zip`: внутри находятся `project.json`, манифест и все найденные локальные изображения, аудио и видео. «Открыть проект» принимает этот пакет, восстанавливает медиа в IndexedDB и также остаётся совместимой со старым JSON.

«Экспорт JSON» сохраняет только структуру проекта и ссылки на локальные ассеты, без тяжёлых файлов. Такой JSON подходит для быстрой резервной копии структуры, но не переносит медиа на другой компьютер.

«Новый» создаёт чистый проект с новым id. «Сброс» дополнительно очищает локальную копию. Оба действия требуют подтверждения.

## Структура

- `src/App.tsx` — оболочка проекта, канва и действия пользователя;
- `src/components/NodeRenderer.tsx` — содержимое и состояния нод;
- `src/hooks/useNodeManagement.ts` — основной сценарий и операции генерации;
- `src/hooks/useAssetPersistence.ts` — сохранение и восстановление изображений, аудио и видео;
- `src/hooks/useCanvasNavigation.ts` — pan, zoom, fit и center;
- `src/hooks/useDraggableNodes.ts` — drag, selection и resize;
- `src/api.ts` — выбор тестового, Mistral или LM Studio-режима;
- `src/assetStorage.ts` — локальное хранилище медиа и стабильные ссылки на ассеты;
- `src/portableProject.ts` — переносимый пакет проекта с JSON и бинарными медиафайлами;
- `src/services/videoGeneration.ts` — браузерная сборка сценовых клипов и итогового видео;
- `src/services/nativeVideoRenderer.ts` — клиент локального FFmpeg renderer с браузерным резервным режимом;
- `server/video-renderer.mjs` — локальная фоновая сборка MP4 без зависимости от активной вкладки;
- `src/mockData.ts` — локальные тестовые ответы;
- `src/project.ts` — схема v1, localStorage, экспортная очистка и проверка импорта;
- `docs/architecture/asset-store.md` — контракт ассетов, текущий жизненный цикл и план развития;
- `AUDIT.md` — исходный аудит;
- `CHANGES.md` — результат текущего этапа.

## Текущие ограничения

- это однопользовательское браузерное приложение без backend и облачной синхронизации;
- публичное безопасное подключение AI требует server-side proxy;
- лёгкий JSON-экспорт не содержит бинарные файлы; для полного переноса используйте «Сохранить проект»;
- семантические библиотеки персонажей и локаций, эпизоды, production-статусы и motion-промпты пока представлены только точками расширения данных;
- локальная сборка видео требует запущенный FFmpeg renderer; `start_canva_story_full_stack.bat` поднимает его автоматически.
